# Security Policy

## Supported Versions

Only the latest release receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by opening a security advisory on GitHub:

https://github.com/TheAntTeam/TheAntFarm/security/advisories/new

Please do **not** report security vulnerabilities through public GitHub issues.

You should receive a response within 48 hours. If you don't, please follow up to ensure your message was received.
